# 数隙 v9.2 Focus Dashboard

## 変更点

v9.1は機能を絞ったが、ホーム感が弱かったため、v9.2では画面構成を再設計した。

## 新しい導線

1. `/login`  
   サイドバーなしの完全独立ログインページ。

2. `/dashboard`  
   XP、レベル、デイリーミッション、次の学習導線を表示するトップページ。

3. `/learn`  
   解説ページ。式を入力して、途中式・グラフ・診断・復習を確認する。

4. `/history`  
   学習履歴。

5. `/system`  
   自己診断。

## 設計意図

ユーザーにいきなり解説画面を見せない。
まず「今日何をやるか」をホームで見せて、そこから解説へ進ませる。
