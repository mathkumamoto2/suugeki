# 数隙 v10 Learning Flow

## 目的

v10では、機能を増やすのではなく、学習導線を編集した。

## 表に出す画面

- `/login`: 粒子アニメーションのログイン画面。デザインはv9.3系を維持。
- `/dashboard`: 今日の1問、XP、ミッション、学習開始ボタン。
- `/learn`: 問題入力 → 解説 → 自力再現 → 診断 → 復習の一本道フロー。
- `/history`: 履歴。
- `/system`: 開発者向け。メインナビからは隠す。

## 重要な変更

- タブ式の「解く/診断/復習」を廃止
- `/learn` は上から順番に進む設計へ変更
- 解説Stepは1枚ずつ表示
- グラフは重複させず1回だけ表示
- 診断後に復習と類題を自動表示
- 応用ツールはDashboardから削除
- main navは ホーム / 学習 / 履歴 のみ
