# 数隙 / Suugeki

数隙は、数学の解答で省略されがちな途中式や思考過程を細かく可視化し、
「公式を暗記する」のではなく「なぜその式変形・解法になるのか」を理解することを目指した学習支援プロジェクトです。

Startup Weekendでプロトタイプを開発しました。

## Concept

数学を、暗記から「思考の地図」へ。

一般的な解説では省略されやすい

- 式変形の理由
- 解法を選ぶ根拠
- 思考の分岐
- 途中計算
- つまずきやすいポイント

を細かく示すことで、学習者が解答プロセスそのものを追えることを目指しています。

## Learning Flow

1. どこで迷ったのかを見つける
2. ヒントを使って思考を進める
3. 解答の流れを自分で再現する

## Target

For STEM students who want to solve, not memorize.
